# خزنة الوكلاء: ربط Claude Code في خمس دقائق (ويندوز)

تحفظ خزنة الوكلاء مفاتيح الواجهات البرمجية (API) وكلمات المرور والملفات الصغيرة مثل مفتاح توقيع تطبيقات أندرويد. يستطيع Claude Code، أو أي وكيل يتحدث بروتوكول MCP، أن يستخدمها دون أن يراها أبداً:

١. يكتب الوكيل اسماً بديلاً مثل `{{secret:github_token}}` في المكان الذي يحتاج فيه المفتاح.

٢. يضع NOAI القيمة الحقيقية لحظة خروج الطلب من جهازك فقط، داخل الملف `src/gate.ts`، وهو الملف الوحيد في NOAI القادر على الاتصال بالشبكة. ولا يفعل ذلك إلا للمواقع التي سمحت بها أنت، وفي الجزء الذي سمحت به من الطلب.

٣. قبل أن يرى الوكيل الرد، يحجب NOAI أي سرّ من أسرار الخزنة يظهر فيه، فإذا أعاد الموقع مفتاحك لا يرى الوكيل إلا الاسم البديل.

٤. كل استخدام، سواء أُرسل أم رُفض، يحصل على إيصال موقّع بمفتاح Ed25519 ومربوط في سلسلة واحدة مع إيصالات NOAI الأخرى. يمكن التحقق من السلسلة دون إنترنت. يذكر الإيصال أيّ سرّ استُخدم، ولأيّ موقع، ومتى، وأيّ وكيل طلبه. ولا يحتوي على القيمة نفسها أبداً.

كل شيء يعمل على جهازك. لا حساب ولا خدمة سحابية، والخزنة نفسها تعمل دون إنترنت. لا يخرج إلا الطلب الذي تطلبه، وإلى المواقع التي سمحت بها فقط. والمفاتيح والإيصالات نفسها لا تغادر جهازك.

## ما تحتاجه

- ويندوز ١٠ أو ١١، وNode.js بإصدار 22.18 أو أحدث (`node --version`).
- هذا المستودع، بعد تشغيل `npm install` مرة واحدة. لا يحتاج NOAI إلى أي ملفات تنفيذية أصلية، فيعمل حتى مع تشغيل Smart App Control.
- Claude Code (`claude --version`).

تُكتب كل الأوامر التالية في PowerShell داخل مجلد المستودع. الأوامر نفسها باللغة الإنجليزية كما هي.

## ١. أنشئ الخزنة (دقيقة واحدة)

</div>

```powershell
npm run vault -- init
```

<div dir="rtl">

يطلب عبارة مرور مرتين ولا يُظهر ما تكتبه. ثم يطبع **بصمة مفتاح الجهاز**، مثل `bf45d217e0f0aaa2`. احتفظ بها، فبها تتحقق من إيصالاتك لاحقاً.

الخزنة هي الملف `.noai\vault.json`. دون عبارة المرور لا يظهر منها إلا عدد الأسرار وتاريخ إضافة كل منها. أما الأسماء والمواقع والقيم فكلها مشفّرة.

## ٢. أضف سرّاً (دقيقة واحدة)

</div>

```powershell
npm run vault -- add github_token --host api.github.com
```

<div dir="rtl">

يطلب القيمة ولا يُظهرها. لا تُكتب القيمة في سطر الأوامر أبداً، فلا تبقى في سجل PowerShell.

- `--host` إلزامي ويجب أن يكون اسم الموقع بالضبط. يمكنك تكراره، ولا يُسمح بالرموز العامة مثل النجمة.
- افتراضياً لا يوضع السرّ إلا في **ترويسة** الطلب (header). أضف `--in url` للواجهات التي تريد المفتاح في الرابط، ولا تضف `--in body` إلا عند الحاجة الفعلية (انظر قسم الحدود).
- للملفات استخدم `--file`:

</div>

```powershell
npm run vault -- add play_upload_keystore --file .\upload-keystore.jks --host signing.example.test --in body
```

<div dir="rtl">

يستخدم الوكيل الملف هكذا: `{{secret:play_upload_keystore:base64}}`. للتأكد من النسخة المشفّرة قبل حذف الملف الأصلي: `npm run vault -- export play_upload_keystore .\check.jks`.

الأمر `npm run vault -- list` يعرض الأسماء والمواقع والأحجام، ولا يعرض القيم أبداً. ولحذف سرّ: `npm run vault -- remove github_token`.

## ٣. شغّل الخزنة للوكلاء (نصف دقيقة)

افتح نافذة PowerShell **منفصلة** واتركها مفتوحة طوال عمل الوكيل:

</div>

```powershell
npm run vault -- serve
```

<div dir="rtl">

يطلب عبارة المرور، ثم يطبع سطراً يبدأ بـ `claude mcp add`. لا يستمع الخادم إلا على جهازك (127.0.0.1)، والضغط على Ctrl+C يقفل الخزنة من جديد.

شغّل الخزنة بنفسك في نافذتك، ولا تدع الوكيل يشغّلها، لأن من يشغّلها يجب أن يكتب عبارة المرور.

## ٤. اربط Claude Code (نصف دقيقة)

انسخ سطر `claude mcp add ...` الذي طبعه الخادم ونفّذه مرة واحدة في أي نافذة. ثم تحقّق:

</div>

```powershell
claude mcp list
```

<div dir="rtl">

يجب أن يظهر `noai-vault` متصلاً. هذه الخطوة تتم مرة واحدة فقط، لأن رمز الدخول محفوظ مشفّراً داخل الخزنة ولا يتغير مع كل تشغيل. لتغييره: `npm run vault -- token --rotate`، ثم اربط من جديد.

## ٥. جرّبه (دقيقة واحدة)

اطلب من Claude Code:

> استخدم noai-vault لعرض أسراري، ثم اتصل بـ https://api.github.com/user باستخدام github_token وأخبرني باسم حسابي.

يرى Claude Code الاسم البديل فقط. يستلم GitHub المفتاح الحقيقي، ويستلم الوكيل الرد بعد حجب أي نسخة من المفتاح فيه. وإذا طلبت منه إرسال المفتاح إلى موقع آخر يأتيه الرد: رُفض الطلب ولم يُرسل شيء.

## ٦. تحقّق مما حدث

</div>

```powershell
npm run vault -- receipts
npm run vault -- verify --expect bf45d217e0f0aaa2
```

<div dir="rtl">

لا يحتاج `verify` إلا إلى ملفين: `receipts.jsonl` و`ledger.jsonl`. لا خزنة ولا عبارة مرور ولا إنترنت، فيمكنك تسليم الملفين لأي جهة لتتحقق بنفسها. ينتهي الأمر برمز خطأ إذا كانت السلسلة مكسورة أو موقّعة بمفتاح آخر.

## ٧. وقّع إصدار أندرويد دون أن يبقى المفتاح على القرص

بعض الأسرار لا تذهب إلى موقع، بل إلى برنامج على جهازك، مثل بناء نسخة الإصدار الذي يحتاج ملف مفتاح التوقيع وكلمات مروره. الأمر `vault run` يسلّمها لبرنامج واحد طوال مدة عمله فقط:

</div>

```powershell
npm run vault -- add play_upload_keystore --file .\upload-keystore.jks --host local.invalid
npm run vault -- add keystore_password --host local.invalid
npm run vault -- run --file NOAI_KEYSTORE=play_upload_keystore --env NOAI_STORE_PASSWORD=keystore_password --env NOAI_KEY_PASSWORD=keystore_password -- .\gradlew.bat bundleRelease
```

<div dir="rtl">

- يضع `--env` السرّ النصي في بيئة ذلك البرنامج وحده.
- يكتب `--file` الملف في مجلد خاص جديد، ويضع مساره في المتغيّر. وعند انتهاء البرنامج، حتى لو فشل، يكتب NOAI أصفاراً فوق الملف ثم يحذف المجلد.
- إذا طبع البرنامج السرّ، تظهر لك نسخة فيها الاسم البديل بدلاً منه.
- كل تشغيل يحصل على إيصال موقّع في السلسلة نفسها.
- الموقع `local.invalid` اسم وهمي، فلا يمكن إرسال سرّ مخصص للبرامج المحلية إلى أي موقع حقيقي.

جُرّب هذا في ٣ أكتوبر ٢٠٢٦ باستخدام أداة `keytool` من Java مع ملف مفتاح تجريبي وكلمة مرور تجريبية. فتحت الأداة الملف عبر الخزنة، واختفى المجلد المؤقت بعدها، ولم تظهر كلمة المرور لا على الشاشة ولا على القرص.

لا يُعرض `vault run` على أي وكيل أبداً، ويطلب عبارة المرور في كل مرة، لأن الوكيل الذي يختار البرنامج يستطيع أن يختار برنامجاً يطبع المفتاح.

## الحدود، بصراحة

- **ليست جداراً بين البرامج.** يعمل Claude Code باسم مستخدم ويندوز نفسه. الوكيل القادر على تشغيل أي أمر باسمك قد يهاجم عملية الخزنة أو ملفاً صدّرته. ما تضمنه الخزنة هو أن المفتاح لا يدخل سياق الوكيل ولا سجلاته ولا خوادم مزوّد النموذج. أبقِ طلبات الإذن في Claude Code مفعّلة، ولا تعطِ أي وكيل عبارة المرور.
- **الموقع المسموح به قد يُساء استخدامه.** إذا سمحت بوضع السرّ في جسم الطلب لموقع يحفظ ما يصله، كموقع ينشر نصوصاً، فقد يحفظ الوكيل السرّ هناك. لهذا يكون الافتراضي الترويسة فقط.
- **حجب النسخ المعادة** يلتقط الأشكال المعتادة: القيمة كما هي، وترميز base64، والترميز داخل الروابط، والصيغة الست عشرية. أما السرّ الذي يعود بشكل آخر فلا يُلتقط، والحماية الأساسية هي قواعد المواقع والأماكن المسموح بها.
- **الإيصال تصريح موقّع من جهازك.** يثبت ما أرسله جهازك وما رفضه، وأن شيئاً لم يُعدَّل أو يُحذف بعد ذلك. ولا يثبت ما فعله الموقع البعيد بالطلب.
- **البرنامج الذي تشغّله بـ `vault run` يستلم القيم الحقيقية.** شغّل فقط أدوات تثق بها مثل Gradle وkeytool وapksigner.
- **الملف المؤقت يُكتب فوقه بالأصفار ثم يُحذف.** لكن أقراص SSD أو النسخ الاحتياطية أو برامج مكافحة الفيروسات قد تحتفظ بنسخة قديمة.
- **لم تخضع الخزنة بعد لمراجعة أمنية مستقلة.**
