NOAI AGENT VAULT

Sign a release without the keystore sitting on disk.

The keystore and its password go to one program for one run, then are wiped. If the program prints the password, you see the placeholder.

  PowerShell
> noai-vault run --env STORE_PASSWORD=test_store_password --file KEYSTORE=test_upload_keystore -- keytool -list -keystore %KEYSTORE% -storepass:env STORE_PASSWORD
